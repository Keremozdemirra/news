# Instagram profile for loopbrief

Set by hand in the Instagram app. Nothing here is posted by the desk.

## Fields

| Field | Value | Limit |
|---|---|---|
| Username | `loopbrief` (availability not checked; fallbacks `loopbrief.ai`, `loopbrief.news`) | 30 |
| Name | `Loopbrief · Daily AI News` | 30 (25 used) |
| Profile picture | `profile/c-stack-black.jpg` | 1080 x 1080 |
| Category | News & Media Website | |
| Link | none until there is a site; the repository is not a reader's page | |

The Name field is searchable, so it carries the words people type: "AI" and "News".

## Bio

The day's AI news in one swipe.

142 characters of 150. Each line is a fact the desk keeps: two posts a day, 48 sources, the number check, the AI disclosure.

## Profile picture

Three options in `profile/`, all in the card system (Libre Franklin 800, black and white, no accent):

- `c-stack-black` (recommended): the full name stays readable at 110 px, where a new account needs its name more than a monogram.
- `a-lb-black`: the monogram, for later, once people know the name.
- `b-lb-white`: the same on white; it fades into Instagram's white background.

## Before going live

1. Professional account (Creator or Business); category above.
2. Two-factor authentication on.
3. Settings, then Account Status: check that the account can be recommended to non-followers.
4. Old Gubbo and Lumo reels: archive them (they stay restorable) or keep them. The grid otherwise opens on reels unrelated to the new account.
5. The ManyChat keyword automations point at those reels; switch them off so they do not answer under news posts.

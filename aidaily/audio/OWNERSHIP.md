# Ownership of these sound files

`bed-1.m4a`, `bed-2.m4a`, `bed-3.m4a` and `sting.m4a` belong to Boardread. `scripts/make_audio.py` computed
every sample from oscillators, filters, envelopes and seeded noise; no recording, sample, loop or preset by
anyone else went into them. Run the script again and you get the same files.

They play under Boardread's videos on Instagram, YouTube, Threads, Bluesky, Telegram and Facebook. Nobody else
holds rights in them, so a rights claim on one of these videos is a mistake and can be disputed with this note
and the script as proof.
